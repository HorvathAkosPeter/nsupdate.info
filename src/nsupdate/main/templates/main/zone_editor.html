  • Here you can delete or add new zone resource records (RRs). To modify a record, clone and delete it. Only newly added (green) records can be edited.
  • The "Edit" button only clones the record and deletes the original.
  • All the changes are applied in a single, atomic operation, if you click the "Apply" button.
  • There is no data validation on the client side. There is also no guarantee that the DNS will accept your modifications.
  • The "sort" column is only to have a feasible sorting: It tries to group data by their sub-domains. It also handles naturally the string data with embedded numbers.
  • There is no way to have multiple rows with exactly the same (name, class, type, data) fields here. If you try to, it will be auto-stepped.
